Organization

Every thread has a home

Connect related sessions, files, and notes to a named workspace hub. Fold a workspace when you need more room; its processes keep running.

The canvas

Arrange your tools. Keep your context.

Place terminals, agents, notes, web pages, Git diffs, files, and live views of other app windows on one canvas. Move and resize each tile to suit the work.

Room

a whole canvas of its own

A separate canvas for a project or area of work. Switching rooms saves the current canvas before opening the next.

Workspace

a circular hub on the canvas

Group related tiles around a named hub. Bind a project folder, choose a color, and fit or fold the group. Drag a tile into the hub to add it.

Tile

terminal · agent · note · web · git · window

Your individual tool. Use ⌘ plus a number to jump to a favorite tile. Double-click to maximize it; press Esc to return to the canvas.

Review in context

See the change. Keep the conversation.

Review your agent’s changes in a Git diff beside the session. Keep the discussion in the terminal and the decision in a note, all within reach.

Attention

See who needs you

Find the sessions that need a reply. Mosaic uses process signals, terminal bells, and explicit agent reports through MCP to track activity. A running agent session stays running until it asks for attention.

Activity status reflects the current session. It resets when you restart Mosaic.

quiet running waiting succeeded · 2m ago failed exit 65

Success and failure badges clear when you focus the tile, or after five minutes.

Overview

See the whole room. Pick up where you left off.

Press ⌥O for an overview. Pick a session to return to its place on the canvas. Hold the shortcut for a quick peek, then release to go back.

Agent · MCP

Your agents share your canvas

Connect an agent through Mosaic’s MCP bridge. It can inspect the workspace, create tiles, focus a session, and report when it needs your input.

Canvas edits appear immediately and use the same undo history as your own actions. Press ⌘Z to undo.

$ claude mcp add mosaic \
-- "$(pwd)/.build/debug/mosaic-mcp"

Run this from your Mosaic checkout. Keep the app open while using the bridge.

Real terminals

Real PTY sessions

Every terminal tile runs a real PTY session. It keeps running when you switch rooms or close its view, and ends when you delete the tile.

Local-first

Local-first, SQLite

Your rooms, workspaces, and notes live in a SQLite database on your Mac. No account or sync service required.
