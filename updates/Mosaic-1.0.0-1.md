# Mosaic 1.0.0 (1) — preview

This is a **preview**, not a notarized release. The app is signed with a
Developer ID Application certificate. Apple has not enabled notarization for
this team yet.

On first open, macOS may say it cannot check the app for malicious software.
Use **System Settings ▸ Privacy & Security ▸ Open Anyway**.

Mosaic is a native, local-first macOS workspace. Rooms, workspaces, and tiles
keep terminals, agents, diffs, notes, and other app windows on one canvas. A
waiting pill counts explicit asks. No account.

## Requirements

- macOS 15 or later
- Apple silicon

## In this preview

- Spatial canvas: rooms, workspace hubs, and tiles
- Terminal, agent, note, web, git, files, and window-stream tiles
- Attention: status, waiting pill, and overview
- **Mosaic ▸ Check for Updates…** (Sparkle). Silent install stays off.
- Room soundtrack through Apple Music, in-process

## Updating later

Newer preview builds, and the first notarized release, arrive through
**Check for Updates…**. Build numbers only increase. The notarized public
release will be **1.0.1**.
